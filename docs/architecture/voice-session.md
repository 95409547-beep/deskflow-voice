# 公共语音会话接口

状态：已实现纯 C++ 模型；尚未接入真实采集、TLS、Deskflow IPC 或豆包适配器。

`src/lib/voice/Session` 接受平台与会话事件，返回待执行的 Effect。模型本身不打开设备、加载原生 DLL、发键、建立网络连接或调用输入法，因此适合在 Mac、Windows 和 CI 中检查相同规则。

## 能力范围

发送端仅支持 MacOS 与 Windows；接收端当前只允许 Windows。Linux CI 仅检查平台无关逻辑，不表示 Linux 已获产品支持。路由必须同时有可信设备身份、当前输入上下文、接收端就绪和已认证标记。

`inputContext` 是接收端适配器验证后的窗口身份与创建代次，不是应用名单、窗口标题或个人 PID 常量。模型不验证操作系统句柄，真实服务接入时必须完成这一步。

## 生命周期

1. `routeChanged` 更新已确认的目标。空闲时不会录音；活动目标变化会停止本轮，End 仍发往原目标。
2. 新的物理 DOWN 调用 `press`。发出 StartCapture 与 Begin，只允许从按下时开始保留有界的本地前导音频。
3. 收到匹配的接收端启动确认后，`receiverStarted` 发出 ForwardAudio；此前不向尚未就绪的输入法转发音频。
4. UP 调用 `release`，停止本地采集、发出一次 End；匹配的 `receiverEnded` 后结束本轮。
5. 接收端先结束时，本地也停止采集。仍按住时需要先松开，下次新的按下才能重新启动。
6. 断线停止本地采集，清空本轮并撤销旧就绪状态；重连不重放 DOWN 或音频。
7. 超时撤销就绪状态并结束本轮；需要服务重新确认状态及新的物理按下。迟到的旧确认不能重新开始采集。

会话序号在每个实例中单调增加。连接的外层协议还必须携带连接代次，建立新连接时创建新实例；本模型的整数序号不替代认证、随机连接身份或防重放协议。

## 服务接入必须补齐的内容

- 认证与能力协商，以及旧端不支持语音时的降级。
- 按住事件去重与键鼠事件协调，避免本地输入法和共享按键重复触发。
- 麦克风权限、真实声源、格式归一、有界队列及设备时钟偏差处理。
- 适配器串行化、原生调用期限、接收端窗口身份和本轮录音归属。
- 断线/锁屏/切换时的幂等结束和用户明确停用时的生命周期。

这些事项尚未被纯状态检查证明。当前测试涵盖两个发送平台共 40 次模拟回合、提前松开、窗口切换、丢线、超时、接收端先停止和 V1 能力拒绝；不等同于任何真人语音识别结果。
