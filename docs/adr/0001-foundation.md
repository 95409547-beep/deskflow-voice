# ADR 0001：首版工程基础与依赖边界

日期：2026-10-27。状态：工程默认决定；公开发行许可、签名与设备安装仍有独立门槛。

## 已采用

1. 首版为 Mac → Windows、Windows → Windows；Windows → Mac 后续开发。
2. 以 Deskflow v1.27.0 / `081f6478e654a112168879e67a41ce7d7e4ae3af` 为首批补丁迁移基线，不直接更新原型运行目录。
3. 使用一个 Qt 6.11.3 SDK 构建 GUI、core 和 Qt 测试；不继续混合 Qt 6.8 与 6.11 的开发应用包。
4. 公共会话模型为无 Qt/无原生副作用的 C++20 库；平台音频、认证、设备与输入法适配另接。
5. 新增基础代码使用与 Deskflow 相容的文件级许可，保留全部上游版权与例外。未导入第三方 GPLv3 设备源码。
6. Windows 原型源码先作内部完整归档，清除个机路径、历史状态与不适合产品的操作脚本后再导入可复用组件。

## 发布前仍要闭合

Siri 设备组件的许可与分发关系、PacketLogger 获取方式、VB-CABLE 分发条件、豆包实际可获取版本的支持矩阵、独立应用/安装标识与签名身份，均不由本次基础库提交解决。

独立进程用于故障隔离，不能自动解决 GPLv2-only 与 GPLv3 的许可兼容问题。设备组件未获发行条件时不会随基础包附带。新增纯模型不调用豆包内部接口，也不要求用户安装相关驱动。

第二台 Windows 实机已由项目负责人确认可用；实际系统与麦克风环境、两端安装和输入结果在后续验收记录中采集。
