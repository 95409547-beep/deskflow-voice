# 跨设备语音交互原型 v0.2

独立、离线的设计预览，双击 `index.html` 使用，无需安装依赖。所有设备、配对码、检测结果和测试文本均为模拟；不访问麦克风、输入法或系统配置。设置只在本页内有效。

## 三页分工

- **使用**：开启状态、当前方向、一条说话提示和一个主要操作；默认不展示组件、按键设置或自启说明。
- **设备**：电脑、本机用途、声音来源，以及接收端输入法/音频组件。Mac 接收不可选。
- **设置**：按住说话键、登录自动准备；完整向导和诊断收在“更多选项”。

## 默认使用流程

首页点“开始使用”，按需补齐设备确认、麦克风权限和一次试说。已经准备好的步骤直接跳过，不再先要求读完固定五页。普通系统麦克风是默认来源，Siri 在设备页另选并独立检查。

已配置的设备直接显示使用提示。故障时才展示具体问题与处理入口。未知豆包版本仍需兼容处理，不通过重复检测假定成功。

## 评审操作

1. 默认查看 Mac 首页，切换“设备”“设置”，检查是否需要的内容才出现。
2. 顶部选择“首次安装”，点“开始使用”，确认演示码、模拟声音准备，再按住测试按钮，松开后完成。
3. 切到 Windows，首页默认显示接收用法；在设备页选择“发送声音”查看 Win → Win。
4. 切到离线、缺组件或不兼容场景，检查对应的解决入口；更换声源后需重新检查。

顶部“查看本机”和“演示场景”是评审工具，不进入正式产品。演示说话只显示预设文字，不代表设备连接、真实识别或安装已经通过。完整五步向导保留在更多选项中，供主动排查或重新配置使用。
