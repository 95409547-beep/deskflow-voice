# 跨设备语音交互原型 v0.1

独立、离线的设计预览，双击 `index.html` 即可使用，不需要安装依赖。不是已接入语音的产品界面；不访问麦克风、蓝牙、输入法、网络服务或系统配置。所有设备、配对码、检测结果和测试文本均为演示数据。设置仅在当前页面内有效。

## 可评审的流程

- Mac 发送页面、Windows 接收页面、Windows 发送页面；Mac 接收不可选。
- 声源、按住说话键、设备身份管理、登录启动、保存/取消。
- 首次设置五步：用途、连接设备、声音与依赖、按键与启动、测试与完成。
- 声源缺失、对端离线、接收音频组件缺失、输入法不兼容；诊断和问题处理入口。
- 模拟按住/松开、连续两轮、演示文本与人工确认；不会请求录音权限或向其他应用输入。

顶部“查看本机”和“演示场景”是评审用控制，不属于正式产品设置。Deskflow 其他设置页在本原型中禁用，继续沿用上游实现。正式 Qt 界面的视觉细节会随平台变化，不承诺与浏览器像素完全一致。

## 操作路径

1. 默认查看 Mac 发送页面；在“查看本机”切到 Windows，检查接收页面，再选“发送声音”查看 Win → Win。
2. 选择“首次安装”，进入设置向导，核对演示码后继续，最后按住测试按钮，松开，确认演示文字后完成。
3. 切到故障场景，查看对应修复入口。输入法不兼容场景不提供一键假定兼容的修复。
4. 在测试中连续按住/松开两次；焦点离开、页面隐藏或关闭弹窗都会结束演示持有状态。

## 实现映射

此原型与 C++/C# 组件没有运行连接。后续 Qt 实现需把界面状态绑定到真实能力、权限、身份和会话模型，检测结果来自服务，真实输入必须经用户确认。基础范围和分阶段门槛沿用[产品方案](../../product/README.md)。

源文件：`index.html`、`prototype.css`、`prototype.js`。无外部字体、脚本或图片依赖。

界面决策与原生接入映射见[设计说明](design-notes.md)，交互检查见[检查记录](ui-validation.json)。`screenshots/` 为实际浏览器预览截图，界面数据仍然全部为模拟。
