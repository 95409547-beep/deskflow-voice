# 依据与决策记录

日期：2026-10-27。当前源码基线为 Deskflow v1.27.0 / 081f647。产品默认技术决定见[ADR 0001](../adr/0001-foundation.md)，实际落地状态见[仓库首页](../../README.md)。

## 既有原型证据

Mac → Windows 原型曾由用户确认在两个 Windows 进程间自然输入并松开停止，技术记录对应四轮会话。两端登录管理和恢复检查也曾通过，但没有因此宣称整机重启或其他设备可用。Windows → Windows 尚无真人验收。原始记录包含个人环境细节，保留在内部快照中，不随公开源码发布。

## 源码与计划的对应关系

| Evidence | Finding | Path / 工作项 |
|---|---|---|
| 既有 Mac → Windows 真人及会话对照记录 | 可以迁移已验证行为，不能直接当作产品包验收 | M1 源码固化 → M2 公共服务 → M6 干净安装 |

| Windows 内部源码导出与 118 项纯托管检查 | 具备接收/控制代码迁移基础，不能替代硬件/录音验证 | components/windows-voice 整理 → M3/M6 |

## 第三方边界

Deskflow 使用文件级 GPLv2-only 与相应例外；SiriRemoteForge 使用 GPLv3 或更新版本，源码直接组合存在兼容门槛。独立进程并不自动解决许可。参考[GNU FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#v2v3Compatibility)、[Deskflow](https://github.com/deskflow/deskflow)及[SiriRemoteForge](https://github.com/HOLODATA-COM/SiriRemoteForge)。

Siri 收音的 PacketLogger/系统组件、VB-CABLE 的分发条件、豆包可获取版本及签名/升级行为均需在发行前复核。参考[设备说明](https://github.com/HOLODATA-COM/SiriRemoteForge#microphone)、[VB-Audio](https://vb-audio.com/Services/licensing.htm)、[豆包官方入口](https://ime.doubao.com/pc)。本仓库未附带这些第三方二进制。
